# Web interface for gene set searching

> [!IMPORTANT]
> This repository is now deprecated and is only kept around for redirection purposes.
> See https://github.com/gesel-inc/web-app for the new app.

This repository implements a web interface to the [**gesel**](https://github.com/gesel-inc/gesel.js) client-side library for gene set searching,
using a variety of publicly available gene sets in the [feedstock repository](http://github.com/gesel-inc/feedstock) repository.
